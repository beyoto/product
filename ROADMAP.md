# Roadmap

Цель: все магазины в одном репозитории и одном Vercel-проекте. Новый магазин создаётся в панели без кода.
Устройство — в [CLAUDE.md](CLAUDE.md). Этот файл обновляется после каждой задачи: что сделано, что дальше.

Договорённости с владельцем:
- Работаем локально (тестовая БД, локальные серверы), **пушим только по команде владельца** — чтобы не мешать его проверкам.
- Ответы — по-русски и простыми словами.

## Как добавить новый магазин

**Обычно:** панель → «Магазины» → «Создать магазин». Всё.

Новый тип магазина (например, «Зоотовары»): добавить запись в `SITE_TYPES` (`back/src/config/siteTypes.js`), задеплоить бэк.

**Старый способ (магазин со своим кодом):**

1. Скопировать похожий `shops/stores/<slug>/` в новую папку, поменять `index.html`, `src/config/store.js`, цвета в `src/index.css`.
2. `store.json` → `{ "key": "<новый_ключ>" }`.
3. Бэкенд: таблицы в БД, файлы роутов по образцу существующих, подключить в `app.js`, строка в `config/stores.js`.
4. Добавить slug в первый rewrite `shops/vercel.json` и в `RESERVED_SLUGS` (`back/src/config/stores.js`).
5. Push → магазин на `https://kg-shop.vercel.app/<slug>/`.
